Задание:  
Реализовать программу-клиент с UI на Python для просмотра, поиска, добавления, удаления и изменения данных ранее созданной базы PostgreSQL. Для интерфейса использовать Qt, для подключения к БД — `psycopg2`.

Референс: интерфейс с полями фильтрации, кнопками действий и таблицей результата.![[0E1141E5-6E44-4892-B341-18B11BB5BE89_1_105_c.jpeg]]![[2770D230-25DA-4F73-A363-C0E3B67D6A66_1_105_c.jpeg]]

**Описание внешнего интерфейса:**  
Оконное приложение, три основные зоны:
- Выпадающие списки: фамилия, имя, отчество, улица. Поля ввода: дом, корпус, квартира, телефон
- Четыре кнопки действий: поиск, добавить, удалить, изменить
- Таблица для отображения результата

Дополнительно можно добавить кнопку Сбросить, которая очищает все фильтры и снова показывает все записи.

**Функционал четырех кнопок:**
- Кнопка Поиск: на основе выбранных и введённых значений формируется WHERE и выполняется SELECT к базе данных. Пустые поля в WHERE не включаются. Если ничего не выбрано, отображаются все строки. После выполнения показывается диалоговое окно с текущим SQL-запросом либо ошибка. В таблице главного окна отображаются найденные строки. После поиска фильтры не сбрасываются.
- Кнопка Добавить: выбранные и введённые значения используются для выполнения INSERT INTO main (...) VALUES (...). Необязательные незаполненные поля сохраняются как NULL. Полностью пустую запись добавлять нельзя. Значения фамилии, имени, отчества и улицы выбираются только из существующих справочников, новые значения через интерфейс не добавляются. После выполнения показывается SQL-запрос либо ошибка, в таблице отображается добавленная строка, поля очищаются.
- Кнопка Удалить: выбранные и введённые значения формируют условие WHERE. Перед удалением программа определяет количество строк, которые будут затронуты, и показывает окно подтверждения. Если ничего не выбрано, WHERE отсутствует и удаляются все строки из main, при этом предварительно показывается отдельное предупреждение. Перед удалением найденные строки сохраняются в памяти Python, поэтому после DELETE их можно показать в таблице красным цветом без создания дополнительной таблицы в БД. После успешного удаления поля очищаются.
- Кнопка Изменить: выбранные и введённые значения в основном окне формируют условие WHERE. После нажатия кнопки открывается окно «Изменить на», где можно выбрать новые значения. Значения второго окна формируют часть SET. Пустые поля в окне «Изменить на» означают «не изменять это поле». Перед UPDATE программа определяет количество затрагиваемых строк и показывает окно подтверждения. Если WHERE пустой, изменение применяется ко всем строкам main с предварительным отдельным предупреждением. После выполнения показывается SQL-запрос либо ошибка, обновлённые строки отображаются в таблице, поля очищаются.

**Общая логика:**  
Значения в основном окне используются как условия WHERE для операций поиска, удаления и изменения. Для операции добавления эти же поля используются как значения новой записи.

Таблица main содержит ссылки на справочники:
fams - fam_id
names - nam_id
otches - otc_id
streets - strt_id

Справочники fams, names, otches, streets через программу не изменяются. Все INSERT, UPDATE и DELETEвыполняются только над таблицей main.

Пользователь работает не с ID, а с нормальными значениями: фамилиями, именами, отчествами и улицами. Программа внутри хранит соответствующие идентификаторы и записывает их в main.

Для отображения данных в читаемом виде используется LEFT JOIN, так как внешние ключи в main могут содержать NULL.

Пример базового отображения:

SELECT
    m.uid,
    f.fam,
    n.nam,
    o.otch,
    s.street,
    m.bldn,
    m.bldn_k,
    m.apprt,
    m.phone
FROM main AS m
LEFT JOIN fams AS f ON m.fam_id = f.f_id
LEFT JOIN names AS n ON m.nam_id = n.n_id
LEFT JOIN otches AS o ON m.otc_id = o.o_id
LEFT JOIN streets AS s ON m.strt_id = s.s_id;

Выпадающие списки загружаются напрямую из справочных таблиц. Даже если какое-то значение сейчас не используется ни одной строкой main, оно всё равно остаётся доступно в списке.

SQL-запросы в Python выполняются параметризованно через psycopg2. Для INSERT, UPDATE и DELETE используется commit(), а при ошибке — rollback().

Разработка происходит на macOS. Среда разработки — VS Code, работа с БД — pgAdmin, СУБД — PostgreSQL. Для интерфейса предпочтительно использовать PyQt6, для подключения — psycopg2.
